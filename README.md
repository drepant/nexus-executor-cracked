# NEXUS Executor v2.7.3 — reversed build

**Платный экзекутор NEXUS, реверс-версия от hoolak.** Работает на актуальном
Roblox (Byfron bypass), поддержка YBA / auto farm / speed glitch скриптов.

## Установка

1. Скачай `NEXUS-v2.7.3.zip` из Releases
2. Распакуй **в любую папку** (не в System32 и не в Program Files)
3. Убедись, что `license.dat` лежит рядом с `NEXUS.exe` — это твой лицензионный
   ключ (cracked, уже активирован)
4. Запусти `NEXUS.exe` от имени администратора (нужно для инжекта в процесс)

## Использование

1. Нажми **ATTACH** — лоадер найдёт процесс Roblox и прицепится
2. Вставь свой скрипт в верхнее окно
3. Нажми **EXECUTE**

## F.A.Q.

**Антивирус ругается на файл?**
Это норма для всех executor'ов — они внедряются в процесс игры, эвристика
антивирусов всегда на это реагирует. Добавь папку в исключения или временно
выключи защиту. Полезных ссылок: погугли "false positive executor".

**Ошибка "license not found"?**
Положи `license.dat` рядом с exe и перезапусти.

**Attach не находит процесс?**
Сначала запусти Roblox и зайди в мир, потом жми ATTACH.
